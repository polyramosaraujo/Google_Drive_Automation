# 💾 Google Drive File Management System

This project aims to optimize the workflow of the Projects team in a company specialized in Coordination and Compatibility of Civil Engineering Projects.


## 🚀 Features

- Registration of new projects via form submission
- Automatic creation of folders in Google Drive according to the company standard
- Scanning the folders of all registered projects
- Checking for the existence of new files
- Identification of the discipline and format of files based on their naming pattern
- Registration of new files in the database
- Checking for edits in existing files
- Updating modified information in the database
- Checking for deletion of existing files
- Recording deletions in the database
- Moving files to their respective organizing folder according to discipline and format
- Copying files to their respective backup folder
- Notifications via Discord and email to the project team about the success of the process or possible errors
